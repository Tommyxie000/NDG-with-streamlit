# Normal Distribution Generator (Streamlit Version)

## 项目概述

这是一个基于 Streamlit 开发的正态分布随机数生成器 Web 应用，用于质量工程领域的统计分析和过程能力评估。该应用能够基于用户输入的参数生成符合特定 CPK 范围的随机数，并提供直观的可视化和分析功能。

## 功能特性

### 核心功能
- **多条件组管理**：支持创建和管理多个独立的条件组
- **随机数生成**：基于目标值、规格上下限、CPK 范围等参数生成随机数
- **统计分析**：计算并显示关键统计量（均值、标准差、CP、CPK、最大值、最小值、范围等）
- **数据可视化**：绘制正态分布拟合曲线，显示规格上下限、目标值、均值等参考线
- **批量处理**：批量生成和查看所有条件组的数据

### 辅助功能
- **Excel 导出**：导出单个条件组或所有条件组的数据到 Excel 格式
- **数据复制**：方便地复制随机数数据
- **响应式设计**：适配不同屏幕尺寸的浏览器
- **现代化界面**：基于 Streamlit 的美观 Web 界面

## 技术栈

- Python 3.10+
- Streamlit (Web 应用框架)
- NumPy (数值计算)
- Matplotlib (数据可视化)
- Pandas (数据处理和 Excel 导出)
- openpyxl (Excel 文件处理)

## 安装说明

### 1. 安装 Python

确保您的系统上安装了 Python 3.10 或更高版本。您可以从 [Python 官方网站](https://www.python.org/downloads/) 下载并安装。

### 2. 克隆或下载项目

将项目文件下载到本地计算机，确保所有文件都在 `NDG web_streamlit` 文件夹中。

### 3. 安装依赖包

打开命令提示符或终端，导航到项目目录，然后运行以下命令安装所需的依赖包：

```bash
pip install -r requirements.txt
```

### 4. 运行应用程序

在项目目录中，运行以下命令启动 Streamlit 应用：

```bash
streamlit run app.py
```

应用程序会在浏览器中自动打开，默认地址为 `http://localhost:8501`。

## 使用指南

### 1. 添加条件组

1. 在左侧边栏中，填写以下参数：
   - 条件组名称
   - 目标值 (Target Value)
   - 规格上限 (Upper Spec Limit)
   - 规格下限 (Lower Spec Limit)
   - CPK 上限 (CPK Upper Limit)
   - CPK 下限 (CPK Lower Limit)
   - 均值 (Mean)
   - 精度 (Precision)
   - 样本数量 (Sample Count)

2. 点击 "添加条件组" 按钮保存当前条件组。

### 2. 生成随机数

1. 在 "生成与查看" 区域，从下拉菜单中选择要生成的条件组
2. 点击 "生成随机数" 按钮生成随机数
3. 生成完成后，您将看到统计信息、分布曲线和生成的随机数

### 3. 批量操作

- **批量生成**：点击 "批量生成所有" 按钮生成所有条件组的随机数
- **批量导出**：在页面底部，点击 "批量导出所有条件组到Excel" 按钮导出所有数据

### 4. 查看结果

每个条件组的结果包括：
- **统计信息卡片**：显示样本数量、均值、标准差、CPK 等关键指标
- **分布曲线**：显示正态分布拟合曲线和参考线
- **随机数表格**：以表格形式显示生成的随机数
- **操作按钮**：复制随机数和导出到 Excel 的按钮

### 5. 导出数据

- **单个条件组导出**：在每个条件组的结果区域，点击 "导出 [条件组名称] 到Excel" 按钮
- **批量导出**：在页面底部，点击 "批量导出所有条件组到Excel" 按钮

导出的 Excel 文件包含：
- 单个条件组：参数信息、统计信息和随机数数据
- 批量导出：所有条件组的数据和汇总信息

## 部署选项

### 本地运行

按照上述安装说明在本地计算机上运行应用。

### Streamlit Cloud 部署

1. 将项目代码上传到 GitHub 仓库
2. 登录 [Streamlit Cloud](https://streamlit.io/cloud)
3. 点击 "New app" 按钮
4. 选择您的 GitHub 仓库、分支和主文件 (`app.py`)
5. 点击 "Deploy" 按钮部署应用
6. 部署完成后，您将获得一个可访问的 URL

### 其他服务器部署

您可以使用 Docker 或直接在服务器上安装依赖并运行应用。

## 故障排除

### 常见问题

1. **应用无法启动**
   - 确保安装了所有必要的依赖包
   - 确保 Python 版本为 3.10 或更高

2. **生成随机数时出错**
   - 检查输入参数是否合理（如规格上限应大于规格下限）
   - 检查 CPK 范围是否合理

3. **Excel 导出失败**
   - 确保安装了 openpyxl 包
   - 检查浏览器是否允许下载文件

4. **图表不显示**
   - 确保安装了 matplotlib 包
   - 尝试刷新浏览器页面

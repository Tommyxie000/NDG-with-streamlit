# 6 Sigma质量管理学习平台

一个专注于数据处理和工具应用的6 Sigma学习网站，从黑带教练的专业角度设计，帮助质量管理人员系统学习和掌握6 Sigma方法论。

## 项目特点

- 专注于数据处理和工具应用，不关注体系和审核
- 从6 Sigma黑带教练的专业角度设计
- 分类清晰，页面美观
- 整合YouTube和B站优质教学视频
- 包含交互式工具演示
- 提供完整培训案例

## 使用说明

### 本地运行
1. 直接在浏览器中打开`index.html`文件
2. 无需服务器，完全本地运行

### 功能使用
1. **工具库**
   - 浏览23个核心工具
   - 点击工具查看详细说明
   - 使用交互式计算功能
   - 查看实时图表结果

2. **视频教程**
   - 浏览YouTube和B站优质视频
   - 按类别筛选视频
   - 点击观看视频

3. **培训案例**
   - 学习制造业、服务业、混合案例
   - 了解DMAIC过程应用
   - 查看改进效果

## 技术栈

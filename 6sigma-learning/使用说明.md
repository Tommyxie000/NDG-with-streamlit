# 6 Sigma质量管理学习平台 - 使用说明

## 快速开始

### 方法一：直接打开HTML文件（推荐）

1. 找到 `6sigma-learning` 文件夹
2. 双击打开 `index.html` 文件
3. 网站将在您的默认浏览器中打开

### 方法二：使用Python服务器

#### Windows用户：

1. 打开命令提示符（CMD）或PowerShell
2. 导航到项目目录：
   ```
   cd "e:\AI coding\6sigma-learning"
   ```
3. 运行服务器：
   ```
   python start_server.py
   ```
4. 在浏览器中访问：http://localhost:8000

#### 或者使用批处理文件：

1. 双击运行 `启动服务器.bat` 文件
2. 等待服务器启动
3. 在浏览器中访问：http://localhost:8000

## 注意事项

1. **无需服务器**：所有HTML文件都是静态的，可以直接在浏览器中打开
2. **图表库**：使用Chart.js CDN，需要网络连接才能显示图表
3. **视频链接**：当前视频链接为示例，需要替换为实际YouTube和B站链接
4. **响应式设计**：网站已适配桌面、平板和移动设备
